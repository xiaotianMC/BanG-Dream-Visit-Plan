# 公共设施开放时间

> 本文件汇总巡礼包涉及的公共设施开放时间及特殊使用规定。<br>
> **注意：** 开放时间可能因节假日、活动、设施维护等原因临时调整，实际使用前请以设施官方公告及现场信息为准。

## 永青文库
> 拍摄巡礼图**无需进入馆内**，店外即可取景；感兴趣的话，也可以顺便进馆看看。

**地址：** 东京都文京区目白台1-1-1<br>
**官方网站：**<br>
[永青文库官网（含开馆日历）](https://www.eiseibunko.com/)<br>
[展览会信息](https://www.eiseibunko.com/)<br>

**开放时间：**<br>
开馆时间：10:00～16:30<br>
最晚入馆：16:00

**休馆日**<br>
- 每周一
- 如果周一为节假日，则开馆，下一个工作日休馆
- 展览更换期间等可能另行休馆
- 年末年始等特殊时期可能调整

**入馆费用**<br>
| 对象 | 费用 |
|---|---|
| 一般 | 1,000日元 |
| 70岁以上 | 800日元 |
| 高中生・大学生 | 500日元 |
| 中学生以下 | 免费 |
| 持有残障手册者及1名陪同者 | 免费 |

**巡礼注意**<br>
永青文库并非全年固定开放的普通公共设施，实际开放情况与当期展览相关。整理巡礼行程时，应优先确认计划访问日期是否处于展览期间。

## JR目白站
> 巡礼点位需要进入**站内区域**，应注意列车运行时间及车站检票口的开放情况。

**地址：** 东京都丰岛区目白3丁目<br>
**官方网站：**<br>
[JR东日本｜目白駅](https://www.jreast.co.jp/estation/stations/1553.html)<br>
[JR东日本｜目白駅时刻表](https://timetables.jreast.co.jp/timetable/list1553.html)<br>

**开放时间：始发～终电**

**巡礼注意**<br>
JR目白站没有固定休站日，通常随始发及终电时间开放。JR东日本官网提供目白駅的实时车站信息及时刻表，实际巡礼请以当天时刻表为准。

**巡礼注意**<br>

如果只是拍摄巡礼图，建议以**能够进入屋顶庭园并实际取景**为准，不要仅根据西武池袋本店的营业时间判断庭园是否开放。

## Sunshine水族馆
> 拍摄巡礼图**需要进入水族馆内部**，应注意设施开放时间。

**地址：** 东京都丰岛区东池袋3-1 サンシャインシティ ワールドインポートマートビル 屋上<br>
**官方网站：**<br>
[サンシャイン水族館官网](https://sunshinecity.jp/aquarium/)<br>
[营业时间・票价页面](https://sunshinecity.jp/aquarium/ticket/)<br>

**开放时间：**<br>
春夏：平日10:00～19:00／周末及节假日9:30～20:00<br>
秋冬：平日10:00～18:00／周末及节假日9:30～18:00<br>
最晚入馆：闭馆前30分钟<br>
> 实际开放时间会根据日期及活动调整，应以官网营业日历为准。

**休馆日**<br>
- 无固定每周休馆日，其他休馆日可能根据营业日历调整
- 2026年度目前公布的休馆日：2026年11月12日
- 特别营业及活动期间可能调整开放时间

**入馆费用**<br>

| 对象        | 费用            |
| --------- | ------------- |
| 高中生以上     | 2,600～3,200日元 |
| 小学生・中学生   | 1,300日元       |
| 4岁以上幼儿    | 800日元         |
| 持有残障手册等人士 | 一般票价半价        |
| 陪同者1名     | 一般票价半价        |

> 成人票价格根据访问日期的票价等级（A～D日程）有所不同。[票价日历](https://sunshinecity.jp/file/aquarium/pdf/aquarium_calendar.pdf)

**巡礼注意**<br>
Sunshine水族馆属于**需要购票进入的商业设施**。实际入馆时，周末、节假日及特定日期可能实施入场限制，官方建议提前购买指定日期、指定时间的门票。<br>
整理巡礼行程时，若计划进入水族馆，应提前确认访问日期的营业时间及票价。
