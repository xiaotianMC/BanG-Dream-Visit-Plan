# BanG Dream系列巡礼指南
更新时间：2026年8月10日<br>
创作者：麦块晓天
## 前言
- 本巡礼包旨在为 BanG Dream! 系列圣地巡礼提供一份较为完整的路线参考。**基于 Anitabi** 收录的大量圣地点位进行筛选，选取其中具有较高巡礼价值的点位，并结合动画正片及相关内容中的其他取景地点进行补充整理。同时根据实际地理位置、交通条件以及作品关联度重新规划路线，补充注释，让即使是首次前往日本进行圣地巡礼的邦友，也能更加轻松地完成巡礼。<br>
- 本计划仍处于持续完善阶段，部分点位的拍摄可行性、交通信息及备注内容可能会继续调整。欢迎提供补充信息或修正建议，共同完善 BanG Dream! 圣地巡礼资料。
## 配套MiriaGo巡礼包
巡礼包基于[MiriaGo](https://github.com/BilyHurington/MiriaGo)软件制作。
### 说明
巡礼包以「全收录」为目标，部分点位的剧中关联度或巡礼必要性较低，但为了提供更完整的巡礼参考，仍保留在巡礼包中。
- 巡礼包整体设计偏向于**还原动画**中的场景移动路线。例如「01 永青文库」片区，巡礼顺序会参考动画中的行动轨迹。在**确保整体行程可执行**的前提下，尽可能还原作品中的路线体验是本巡礼包的核心目标。因此，部分路线可能**并非**现实交通或步行效率最高的方案，而是为了贴近动画场景顺序进行了调整。
- 部分片区及点位设有**可选**标记，可选标准综合考虑**剧中重要程度**、**交通便利程度**等因素。您可以根据自身行程安排，选择是否前往这些区域或点位巡礼。
- 为方便查找与路线规划，每个片区均设置了专属编号。动画巡礼片区采用**数字编号**，内部点位按照推荐巡礼顺序排列；音乐 MV 巡礼片区采用**字母编号**。其中，A 片区与 01～07 片区位置接近，建议**合并安排巡礼**；B 及之后的片区则可根据自身行程，按照片区内点位顺序单独进行巡礼。
- 由于《栞》《描绘未来（エガクミライ）》《Yes! BanG_Dream!》三首歌曲的巡礼内容具有特殊性，其相关点位未归入 MV 补充包，而是**作为正片巡礼包**内容进行收录。

- 需要注意，部分线路（如都电荒川线）车内空间有限，对**大件行李携带存在限制**，因此**不建议**携带大型行李进行巡礼移动。

### 第1天
#### 片区：01-07（都电荒川沿线）
#### 行程提示
略微紧张，但在正常速度下基本可以在一天之内巡礼完成。若您认为安排较紧，可将06片区巡礼挪到第2天，或放弃04片区部分点位。<br>
**①** 01永青文库片区按照计划内路线**顺时针**巡礼最佳。<br>
**②** 05、06片区同时巡礼为最佳。这样可以体验高松灯的回家路。

**※请自行查阅、判断你乘坐的线路是否为东京都交通局运营**。<br>
